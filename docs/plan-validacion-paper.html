Plan de validación paper — 8 semanas

Objetivo: decidir con datos si el bot está listo para dinero real.

← Volver al dashboard

Semana 0

  • Bot solo en GitHub Actions + Telegram + dashboard activos
  • Anotar equity inicial y capital objetivo live (~$500)
  • Ideal: resetear paper a ~$500 para simular sizing real

Semanas 1–2 — Estabilidad

Meta: ≥8/10 ciclos exitosos, Telegram diario, 0 HALT.

Semanas 3–4 — Trading

Meta: drawdown <10%, órdenes coherentes, 0 rechazos Alpaca.

Semanas 5–6 — Riesgo

Meta: drawdown <15%, sin circuit breaker inesperado.

Semanas 7–8 — Go / No-go live

Requisitos: ≥30 ciclos OK, keys live listas, reset de estado, riesgo conservador.

No-go si drawdown >15%, fallos técnicos o expectativas irreales.
